# Voxi icon alternatives

These SVG pairs preserve recent tray-icon layouts for quick comparison.

- `v1.15.5-wide-*`: wider board with evenly distributed marks and a raised clip
- `v1.15.6-slim-flush-*`: slimmer board with a flush clip
- `legacy-five-bar-*`: original five-mark clipboard layout in SVG and ICO formats

The active icon sources remain `../voxi.svg` and `../voxi-active.svg`.
